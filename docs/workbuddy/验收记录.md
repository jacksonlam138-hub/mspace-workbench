# M·SPACE 麦当劳工作台｜验收记录

更新时间：2026-10-23 10:50（GMT+8）。分支：`codex/workbench-implementation`（未推送远端）。

## 一、启动方式

```sh
cd app
pnpm install          # 首次
pnpm mcp:server       # 服务端 MCP 适配，http://127.0.0.1:10243（未配置 Token 时为演示模式，如实上报）
pnpm dev              # 前端，http://127.0.0.1:10241（Vite 将 /api/mcp 代理到 10243）
```

可选环境变量（见 `app/server/.env.example`，不含任何密钥）：
- `MCD_MCP_TOKEN`：麦当劳 MCP Token（https://open.mcd.cn/mcp 申请），仅服务端使用
- `MCD_MCP_URL`：默认 `https://mcp.mcd.cn`
- `MCP_ADAPTER_PORT`：默认 `10243`
- `MCP_ALLOW_WRITES`：默认拦截全部写操作工具；本轮验收不开启
